HERO BACKGROUND VIDEO
=====================

Drop ONE file here and the landing page will use it automatically as the
cinematic hero background (muted, autoplay, looping):

    hero.mp4     (preferred)   -- H.264 .mp4
    hero.webm                  -- VP9 .webm
    hero.mov                   -- QuickTime

Guidance for best results:
  * Landscape / 16:9, at least 1920x1080.
  * Keep it SHORT (5-12 seconds) and small (ideally < 8 MB) so it loads fast.
    The file is embedded inline, so smaller = snappier. Use 720p if unsure.
  * Silent / no important audio (it plays muted).
  * Something evocative: a table of world dishes, a bustling food market,
    a slow pan over a heritage site, steam rising off a dish, etc.

No file here? The page falls back to the still photo at
assets/food/_hero.jpg -- nothing breaks.
